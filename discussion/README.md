# FED-Indeed — Discussion Content

Seed content for the repository's GitHub Discussions. Maintainers: when
Discussions are enabled, create the categories in
[categories.md](categories.md), then post the files in
[pinned/](pinned/) as pinned threads and the ones in
[starters/](starters/) as the first normal threads.

Everything here is also useful standalone reading — the field stories and
ideas don't depend on GitHub.

## Maintainer Setup Checklist

1. Enable Discussions in repo Settings → General → Features.
2. Create categories per [categories.md](categories.md) (order matters for
   the sidebar).
3. Post the two `pinned/` files, mark both as pinned announcements.
4. Post the three `starters/` threads in their categories.
5. Edit `.github/ISSUE_TEMPLATE/config.yml` contact links if the category
   slugs differ from the defaults (Q&A, Ideas, Show and tell).

## Privacy Note

This folder exists to be copied *into* GitHub — but the rule travels with
it: **no real resumes or personal data in any thread, ever.** Synthetic
examples and redacted descriptions only. Users come here because they
don't want their data spread around; that trust is the community's
foundation.
