# [Pinned] Community rules — the two-minute version

> Maintainer note: post in **📣 Announcements**, then pin alongside the
> welcome thread. Delete this note before posting.

The long versions live in the
[Code of Conduct](../../CODE_OF_CONDUCT.md) and
[SUPPORT.md](../../SUPPORT.md). This is the short version, because pinned
threads should be readable while your coffee is still hot.

## 1. Protect people's data — zero tolerance

- **No real resumes, screenshots of real resumes, or personal data** in any
  thread. Synthetic examples and redacted descriptions only.
- If you're asking for help with a specific document, describe it: how
  many pages, columns, what tool created it. That's almost always enough.
- If you see personal data posted, flag it for maintainers immediately.
  We remove it on sight.

## 2. Be decent

- The [Contributor Covenant](../../CODE_OF_CONDUCT.md) applies everywhere
  here: issues, PRs, discussions, polls, DMs among community members about
  project matters.
- Everyone in a job-search community is carrying some stress. Assume good
  faith, give grace, report conduct problems (see
  [SUPPORT.md](../../SUPPORT.md#conduct-reports)) instead of fighting.

## 3. Post in the right place

- **Question?** → Q&A (not issues).
- **Idea?** → Ideas — big architectural ones *must* start there.
- **Bug?** → an issue with the bug template (see
  [SUPPORT.md](../../SUPPORT.md)).
- **Security?** → never in public; use the private advisory path in
  [SECURITY.md](../../SECURITY.md).

## 4. Don't ask us to help you lie

We help you say *true* things in the words filters understand. We won't
help you claim experience you don't have — not for moralizing reasons, but
because it fails at the interview and burns the community's credibility
with it. See the [rewrite prompt rules](../../prompts/rewrite_suggestions.md)
for exactly where the line sits.

That's it. The rest is common sense and kindness. 💛
