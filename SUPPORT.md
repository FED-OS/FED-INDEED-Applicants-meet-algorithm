# Getting Support with FED-Indeed

> **Rule of thumb:** questions → Discussions · bugs → Issues ·
> vulnerabilities → private security advisory.

## 📚 Read First

1. [usage.md](usage.md) — how to run and read the audit
2. [FAQ.md](FAQ.md) — common questions and misconceptions
3. [wiki/](wiki/) — deep dives: scoring methodology, ATS field guide,
   troubleshooting

## 💬 Questions & Help

Open a topic in
[GitHub Discussions](https://github.com/YOUR_USERNAME/FED-Indeed/discussions)
using the **Q&A** category. The community and maintainers answer there, and
answers stay searchable for future users. Please include:

- What you expected vs. what happened
- Steps to reproduce (with a **synthetic** resume — never real personal data)
- Your Python, Streamlit, and OS versions

## 🐛 Bugs

Use the [bug report template](https://github.com/YOUR_USERNAME/FED-Indeed/issues/new?template=bug_report.md).
Attach redacted or synthetic files only.

## ✨ Feature Ideas

Use the [feature request template](https://github.com/YOUR_USERNAME/FED-Indeed/issues/new?template=feature_request.md),
or start a discussion thread under **Ideas** for broader proposals — see the
starter threads in [discussion/](discussion/).

## 🔒 Security & Conduct Reports

- Vulnerabilities: [SECURITY.md](SECURITY.md) — private disclosure only.
- Code of Conduct violations: see
  [Conduct Reports](#conduct-reports) below.

### Conduct Reports

Report harassment or conduct violations by email to the maintainer at
`YOUR_EMAIL@example.com`. Include links/quotes and, if safe, timestamps.
Reports are handled per the [Code of Conduct](CODE_OF_CONDUCT.md).

## ⏱️ Response Expectations

This is a community project maintained in spare time. Expect a response
within a few days; discussions may take longer. If nobody replies within a
week, a polite bump is welcome.

## 💛 Other Ways to Get Help

- Search existing [issues](https://github.com/YOUR_USERNAME/FED-Indeed/issues)
  and [discussions](https://github.com/YOUR_USERNAME/FED-Indeed/discussions)
  before opening a new thread.
- For Streamlit platform questions, the
  [Streamlit forums](https://discuss.streamlit.io) are excellent.
