# Pricing

**FED-Indeed is free, forever, under the MIT License.** There is no paid
tier, no pro version, no ads, and no data monetization. This page exists
only to state that clearly and to be transparent about costs that *do*
exist if you choose to run it yourself.

## Cost to Use

| Item | Cost |
|---|---|
| The code (self-hosted, local) | **$0** — run `streamlit run app.py` |
| Public deployment on Streamlit Community Cloud | **$0** (free tier, one app) |
| Any future "official" hosted demo | **$0**, ad-free |
| Your data | Never sold, never stored |

## Costs You Might Incur (Self-Hosting Beyond the Free Tier)

- **Hosting** — if you outgrow Streamlit Community Cloud's single free app
  and deploy on a VPS/serverless platform, you pay your provider directly.
  Typical cost: a few dollars per month.
- **LLM features** — the optional semantic features driven by the templates
  in [prompts/](prompts/) use *your own* API key and *your* provider's
  billing. The core scanner works fully without any API key.
- **Nothing else.** There are no license keys, seat fees, or upsells.
